# EduNexus Frontend (demo scaffold)

This repository contains a frontend scaffold for the EduNexus Smart Institute Management System built with Next.js (App Router), React, Tailwind CSS, and a component-first architecture.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes:
- The app uses mock auth and localStorage-based theme persistence for demo purposes.
- Implement backend endpoints and secure auth storage (http-only cookies) for production.
